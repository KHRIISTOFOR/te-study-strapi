# 🎛️ TE.STUDY Strapi CMS

Это CMS (система управления контентом) для сайта TE.STUDY, развернутая на Railway.app.

## 🏗️ Архитектура

```
🌐 Фронтенд (te-study.com) → 🎛️ Strapi CMS (Railway.app) → 🗄️ PostgreSQL
```

## 🚀 Быстрый старт

### Локальная разработка

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run develop

# Сборка для продакшена
npm run build

# Запуск продакшен версии
npm run start
```

### Деплой на Railway

1. Подключите репозиторий к Railway.app
2. Настройте переменные окружения
3. Railway автоматически задеплоит приложение

## 📊 Управление контентом

### Доступ к админке
- **URL:** `https://your-strapi-app.railway.app/admin`
- **Логин:** Создается при первом запуске
- **Функции:** Полное управление контентом сайта

### Типы контента

- **🏛️ Университеты** - Информация о вузах Северного Кипра
- **💬 Отзывы** - Отзывы студентов
- **🛠️ Услуги** - Услуги компании
- **📝 Заявки** - Заявки с сайта
- **📞 Контакты** - Контактная информация
- **📅 Дедлайны** - Важные даты
- **📰 Блог** - Статьи и новости
- **⚙️ Настройки** - Общие настройки сайта

## 🔧 API Endpoints

- `GET /api/universities` - Список университетов
- `GET /api/testimonials` - Отзывы
- `GET /api/services` - Услуги
- `GET /api/contacts` - Контакты
- `GET /api/deadlines` - Дедлайны
- `GET /api/blog-posts` - Статьи блога
- `GET /api/site-setting` - Настройки сайта

## 🛡️ Безопасность

- Все API защищены CORS
- JWT токены для аутентификации
- Переменные окружения для секретных ключей

## 📞 Поддержка

При возникновении проблем:
1. Проверьте логи в Railway
2. Убедитесь в правильности переменных окружения
3. Проверьте подключение к базе данных
